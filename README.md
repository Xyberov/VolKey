# VolKey

VolKey переводит жесты на кнопках громкости в переключение треков Windows:

- `громкость +`, `громкость -`, `громкость +` — следующий трек;
- `громкость -`, `громкость +`, `громкость -` — предыдущий трек.

## Запуск в Visual Studio

1. Откройте `VolKey.sln` двойным кликом.
2. Нажмите зелёную кнопку запуска или клавишу `F5`.
3. После запуска VolKey появится в области уведомлений рядом с часами.

Окно можно закрыть крестиком: программа останется работать в фоне. Для полного выхода используйте пункт **Выйти** в меню иконки VolKey либо кнопку в окне.

## Ограничение первой версии

VolKey распознаёт нажатия, которые Windows передаёт как стандартные клавиши громкости. Пока жест распознаётся, сами нажатия также меняют системную громкость. В следующей версии можно добавить режим с сохранением исходной громкости при успешном жесте.
