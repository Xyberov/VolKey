## Что это

**VolKey** — небольшая программа для Windows, которая добавляет управление музыкой через короткие последовательности кнопок громкости. Она работает в фоне и живёт в области уведомлений рядом с часами.

Подходит для наушников, клавиатур и других устройств, которые передают в Windows стандартные команды `Громкость +` и `Громкость −`.

## Жесты

Стандартные комбинации:

| Нажатия | Действие |
| --- | --- |
| `Громкость +` → `Громкость −` → `Громкость +` | Следующий трек ⏭ |
| `Громкость −` → `Громкость +` → `Громкость −` | Предыдущий трек ⏮ |

В настройках можно добавить свои жесты или изменить эти. Доступные действия:

- следующий трек;
- предыдущий трек;
- пауза / воспроизведение;
- выключить / включить звук.

Комбинация — от 2 до 4 нажатий, и в ней обязательно есть обе кнопки, чтобы обычная регулировка громкости (`+ + +`) не превращалась в жест. Если одна комбинация — начало другой (например, `+ −` и `+ − +`), короткая сработает только после паузы, чтобы длинную можно было ввести.

По умолчанию VolKey возвращает исходную громкость (и режим «без звука») после успешно распознанного жеста. Одиночные нажатия продолжают менять громкость как обычно, а удержание кнопки считается одним нажатием.

## Возможности

- Глобальная обработка кнопок громкости — приложение не нужно держать открытым.
- Работает с любым медиаплеером, который понимает медиаклавиши: Spotify, браузер, Яндекс Музыка, VK Музыка и другие.
- Свои комбинации и действия: треки, пауза, выключение звука.
- Значок и меню возле часов: открыть настройки, включить/выключить жесты, выйти. Когда жесты выключены, значок серый.
- Автозапуск вместе с Windows — программа стартует тихо, без окна.
- Повторный запуск не создаёт вторую копию, а открывает окно уже работающей.
- Включение и выключение обработки без закрытия программы.
- Настройка максимальной паузы между нажатиями.
- Возврат громкости после распознанной комбинации.
- Отключаемые уведомления о выполненном действии.

## Настройки

| Настройка | Что делает |
| --- | --- |
| **Включить обработку жестов** | Временно включает или выключает реакции на комбинации. |
| **Запускать вместе с Windows** | Автоматически запускает VolKey при входе в систему. |
| **Возвращать громкость после жеста** | Убирает случайное изменение громкости после жеста. |
| **Показывать уведомление о действии** | Короткое уведомление, например «Следующий трек» или «Звук выключен». |
| **Макс. пауза между нажатиями** | Сколько можно ждать между соседними нажатиями комбинации: 250–1500 мс, по умолчанию 550 мс. |
| **Жесты** | Таблица «комбинация → действие»: добавить, изменить, удалить или вернуть стандартные. |

> Крестик в окне не выключает VolKey: программа остаётся работать в фоне. Чтобы завершить её полностью, нажмите **«Выйти»** в меню значка возле часов или кнопку в настройках.

## Запуск для разработки

Нужны Windows и [Visual Studio](https://visualstudio.microsoft.com/ru/) с компонентом **Разработка классических приложений .NET**.

1. Склонируйте репозиторий или скачайте его через **Code → Download ZIP**.
2. Откройте файл `VolKey.sln` в Visual Studio.
3. Нажмите `F5` или зелёную кнопку запуска.
4. После запуска VolKey появится в области уведомлений рядом с часами.

## Выпуск релиза

1. Поднимите `Version` в `VolKey.csproj` и закоммитьте изменения.
2. Поставьте тег и отправьте его на GitHub:

   ```powershell
   git tag v1.2.0
   git push origin v1.2.0
   ```

GitHub Actions соберёт портативный exe и установщик и опубликует релиз. Версию программа берёт из тега.

## Ручная сборка установщика

1. Соберите один самодостаточный exe (на компьютере пользователя .NET не понадобится):

   ```powershell
   dotnet publish VolKey.csproj -c Release -p:PublishProfile=Installer
   ```

   Результат появится в папке `publish\`.
2. Откройте `VolKeySetup.iss` в [Inno Setup](https://jrsoftware.org/isinfo.php) и нажмите **Compile**. Установщик появится в папке `Output\`.

Версия программы задаётся один раз — в свойстве `Version` файла `VolKey.csproj`; установщик берёт её из exe.

## Структура проекта

```text
VolKey/
├── MainForm.cs                 # Окно настроек и значок возле часов
├── Program.cs                  # Точка входа, защита от второй копии
├── VolKeyApplicationContext.cs # Управление жизненным циклом приложения
├── VolKeySetup.iss             # Скрипт установщика Inno Setup
├── Assets/VolKey.ico           # Иконка (генерируется tools/make-icon.ps1)
├── Services/
│   ├── KeyboardHook.cs          # Глобальное отслеживание кнопок громкости
│   ├── Gestures.cs              # Комбинации, действия и их проверка
│   ├── GestureMatcher.cs        # Логика сопоставления нажатий с жестами
│   ├── GestureRecognizer.cs     # Буфер нажатий и таймер паузы
│   ├── MediaController.cs       # Отправка медиаклавиш плееру
│   ├── AudioVolumeService.cs    # Сохранение и возврат громкости
│   ├── AutoStartService.cs      # Автозапуск Windows
│   ├── SettingsService.cs       # Хранение настроек в %LOCALAPPDATA%\VolKey
│   ├── ShowWindowSignal.cs      # Открытие окна работающей копии при повторном запуске
│   └── AppIcons.cs              # Иконки для окна и трея
├── tests/VolKey.Tests/          # Тесты распознавания жестов (dotnet test)
└── VolKey.sln
```
